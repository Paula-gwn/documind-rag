# DocuMind: AI Document Intelligence with RAG

DocuMind is an end-to-end AI application that allows users to upload documents, retrieve relevant context, and ask grounded questions using Retrieval-Augmented Generation (RAG). The system supports document ingestion, preprocessing, semantic search, LLM-based answer generation, evaluation, and deployment through both API and web UI.

## Features
- Document upload and text extraction
- Semantic chunking and embedding
- Vector search over document content
- Grounded question answering with cited sources
- FastAPI backend
- Streamlit interface
- Basic RAG evaluation

## Tech Stack
Python, LangChain, Sentence Transformers, FAISS, FastAPI, Streamlit, Docker, Pytest
